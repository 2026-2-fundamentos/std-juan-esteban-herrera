# LAB_02_pandas

## Propósito

Resolver transformaciones, agregaciones y combinaciones de datos tabulares con Pandas. El laboratorio desarrolla la capacidad de seleccionar, agrupar, resumir y combinar datos para producir resultados descriptivos reproducibles.

## Competencia evaluada

Construye resúmenes descriptivos reproducibles a partir de tablas usando operaciones de Pandas apropiadas para la pregunta planteada.

## Datos

La carpeta `data/` contiene tres archivos tabulados con encabezados:

- `tbl0.tsv`: identificador, categoría, valor numérico y fecha.
- `tbl1.tsv`: identificador y listas de categorías codificadas como texto.
- `tbl2.tsv`: identificador y valores que se deben combinar o transformar.

Cada archivo `src/pregunta_*.py` contiene el enunciado y la función que debe resolverlo.

## Restricciones

- Use Pandas para cargar y transformar los datos.
- No modifique los archivos de `data/` ni los de `tests/`.
- Cada función debe retornar el resultado solicitado; no debe imprimirlo ni escribir archivos de salida.
