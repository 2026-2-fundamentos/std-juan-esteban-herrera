# Políticas y supervisión humana

## Problema

Una unidad de crédito recibe puntajes predictivos para solicitudes. Debe definir qué recomendaciones se aprueban, cuáles se rechazan y cuáles pasan a revisión humana. El caso se inspira en la discusión pública de decisiones crediticias automatizadas: el puntaje es evidencia, no una orden ni un producto.

## Competencia

Diseñar reglas de decisión, zonas de incertidumbre, escalamiento y trazabilidad de una recomendación. La salida no automatiza crédito: establece una política que conserva responsabilidad humana.

## Entregable

`submission/review_policy.csv` asigna a cada solicitud una acción y una razón verificable. Los datos son una muestra pedagógica pequeña de solicitudes anonimizadas; los puntajes se tratan como insumo entregado por Predictiva.
