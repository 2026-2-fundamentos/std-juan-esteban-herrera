# Política desde evidencia y restricciones

## Problema

Un distrito debe distribuir 40 cupos de tutoría entre grados con distinto número de estudiantes y distinta ganancia esperada. El caso adapta la pregunta de asignación educativa de Project STAR (Tennessee): la evidencia disponible informa beneficios esperados, pero no determina por sí sola una política. La dirección puede comparar tres reglas simples y debe respetar capacidad y una garantía mínima para cada grado.

## Competencia

Construir y defender una política a partir de evidencia, valor y restricciones. No se enseña un algoritmo de Investigación de Operaciones: las alternativas están explícitas y se comparan por consecuencias.

## Entregable y procedencia

`submission/policy_recommendation.csv` documenta la política, cupos por grado, ganancia esperada, cumplimiento de restricciones y razón de descarte. `data/policy_options.csv` es una reducción pedagógica del contexto de Project STAR; sus parámetros representan evidencia hipotética para el caso, no estimaciones publicadas ni un nuevo conjunto de datos.
